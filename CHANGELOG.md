# История изменений

## [1.0.0] — 2026-09-04

### Добавлено

- Создание рецептов через Telegram-бота.
- Выбор категории рецепта.
- Добавление ингредиентов.
- Добавление фотографии рецепта.
- Добавление этапов приготовления.
- Добавление фотографии к этапу приготовления.
- Сохранение рецептов в PostgreSQL.
- Управление состоянием пользовательского сценария.
- Docker-конфигурация для запуска приложения.

### Архитектура

- Разделение проекта на Domain, Application, Infrastructure и Telegram.
- Использование MediatR.
- Использование Entity Framework Core.
- Использование Repository pattern.
- Использование `IDbContextFactory`.
